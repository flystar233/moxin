Claude Code

它在等你确认时，你会知道

电脑端程序挂在 Claude Code 的 hooks 上：开始运行、需要你确认、任务完成，屏幕上都会更新，后两种还会响一声提示音。短按菜单键就算确认看过了。

  • 运行中提交提示词后
  • 等待确认提示音 A
  • 完成提示音 B
