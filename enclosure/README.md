# 墨水屏阅读器外壳 v1（亚克力面板）

对应 PCB：`PCB_PCB1_1_2026-11-06`（坐标文件和 11-02 版相比只多了 TP1、TP2，外形、定位孔、按键、Type-C 位置都没变）。
尺寸沿用设计文档 eink-docs 里的外壳数据（开窗、螺丝柱、各开孔）；外形 118 × 67 R4（11-12 由 115 加长，见下面“屏幕错开 3mm”），面板从“前壳一体面框”改成亚克力。eink-docs v4.44 起已按这套外壳同步（`assets/board-data.js` 的 `CASE`；**11-12 的错开和排线槽还没同步**），客户版规格书 eink-brief 的外壳制造页也从这里取文件。改了这里的尺寸，记得同步 `CASE` 再重建两边。

## 两个版本

外形、开孔位置、叠层两版完全一样，只是按加工方式调了间隙和细节：

| | FDM 版（`eink-case-fdm.scad`） | 手板版（`eink-case-master.scad`） |
|---|---|---|
| 用途 | 自己的打印机，0.4 喷嘴 + PLA | 光固化 / CNC 手板，之后翻硅胶模复模（PU 真空注型） |
| 键帽和开孔间隙（每边） | 0.3 | 0.2（复模件有收缩和披锋；以后开注塑模可到 0.15） |
| 自攻底孔 | Ø1.7 | Ø1.6 |
| 翘板凸棱 | 0.8 × 0.4 | 0.6 × 0.3 |
| 电源键凸点 | Ø1.0 高 0.3 | Ø0.8 高 0.2 |
| 菜单键凹面 | 0.3 | 0.2 |
| 圆键底部 | 削平 0.2（侧躺打印贴平台） | 不削，整圆 |
| 键帽摆放（print 排版） | 侧躺，不用支撑 | 法兰面朝下（手板厂会自己摆） |
| 默认导出 | `part = "print"`：整套平放一个文件 | `part = "print"`：整套平放一个文件，再拆成三个零件文件 |

两版的键帽结构相同：法兰片下面和两端都是 45° 斜面，没有往下悬空的法兰。

## 导出 STL

1. 装 OpenSCAD（`winget install OpenSCAD.OpenSCAD`，或 openscad.org 下载）。
2. 打开要的那一版入口文件（`eink-case-fdm.scad` 或 `eink-case-master.scad`），F6 渲染、F7 导出。入口文件和 `eink-case.scad` 要放在同一个文件夹。
3. 换零件：改入口文件里的 `part`——`"print"`（整套平放）、`"keytest"`（试打件）、`"frame"`、`"back"`、`"keys"`、`"assembly"`（装配图，只能看，不能打印）。
4. 命令行也行：`openscad -o frame.stl eink-case-master.scad`（part 在入口文件里改）。

建议文件名带上版本，比如 `stl/fdm-print.stl`、`stl/master-frame.stl`。

> 如果你用的工具只能打开单个 .scad 文件（不支持 include），就直接打开 `eink-case.scad`，把开头的 `VARIANT` 改成 `"fdm"` 或 `"master"`。

## 手板 / 复模

- **给手板厂的文件**：`master-frame.stl`、`master-back.stl`、`master-keys.stl` 三个，外加这份 README 里的叠层图和装配说明。做 CNC 手板的厂一般要 STEP，OpenSCAD 导不出 STEP，可以让厂家从 STL 转，或者先做光固化手板。
- **材料**：中框、后盖用 ABS 类 PU（耐温 70～80°C，比 PLA 好），白色原色或喷哑光白；键帽用硬一点的 PU（邵氏 D 80 以上），不然按久了会变形。
- **复模次数**：一套硅胶模一般能翻 15～20 件，中框和后盖各一套，3 个键帽可以放在同一套模里。
- **螺丝**：PU 件直接用 ST2.0 自攻，拆装十来次没问题。**埋不了铜螺母**：M2 铜螺母要 Ø5 以上的螺丝柱，现在的 Ø4.5 柱子外侧离壳外表面只有 0.05、内侧离屏幕玻璃只有 0.29，加粗就会顶出壳外、碰到玻璃。牙滑了就换 ST2.2 × 6。

## 自己用 FDM 打（`eink-case-fdm.scad`）

**先打试打件**：`part = "keytest"`，中框底边按键那一段（44 × 6）+ 3 个键帽，十几分钟。装上试：键帽在孔里能自由滑、不晃，翘板压一头另一头不动。太紧把 `CLR` 加 0.05，太松减 0.05，再打整个中框。

| 零件 | 摆放 | 层高 | 墙 | 支撑 | 其他 |
|---|---|---|---|---|---|
| 中框 | 前沿朝下 | 0.16 | 4 圈 | 不要 | 开孔都是 ≤17mm 的横向桥接；开“象脚补偿” 0.15，不然前沿外扩，亚克力对不齐 |
| 后盖 | 外表面朝下 | 0.16 | 4 圈 | 不要 | 外表面贴纹理 PEI 板会有磨砂面；沉头孔朝下没关系 |
| 键帽 | 侧躺（已摆好） | 0.08～0.12 | 全实心 | 不要 | 加 3mm brim；速度 30mm/s、风扇 100%；多打一两套备用 |

- **自攻螺丝**：底孔已按 FDM 放到 Ø1.7，ST2.0 拧到底就停，PLA 滑牙后很难救。天线旁那个角用 M2 尼龙螺丝，先用 M2 丝锥攻一下。
- **PLA 怕热**：50～60°C 开始软，别放在夏天的车里、暴晒的窗台；桌面、包里没问题。
- **建议中框、后盖用 PETG**：PETG 没有 PLA 硬，但更韧——摔了是凹、不是裂；自攻螺丝拧几次柱子也不容易裂；70～80°C 才软。键帽用 PLA 还是 PETG 都行，PLA 的凸棱、凹面更清楚。模型尺寸不用改，换料后先打 keytest，PETG 一般偏胖一点，紧了 `CLR` 加 0.05。

  | PETG 参数 | 值 |
  |---|---|
  | 喷嘴 / 热床 | 235～245°C / 75～85°C |
  | 风扇 | 30～50%，桥接 100% |
  | 速度 | 外墙 ≤40mm/s，桥接 20mm/s |
  | 回抽 | 比 PLA 多 0.5～1mm，开“擦拭”，减少拉丝 |
  | 平台 | 光面 PEI 先涂固体胶隔离，不然粘太牢会撕坏板面；纹理 PEI 直接打 |
  | 颜色 | PETG 比 PLA 更透，选“不透光白 / opaque white” |
- **白色**：白 PLA 偏透，侧壁在强光下能隐约透出里面的 PCB，介意就选“哑光白”或“高遮盖白”。
- **键帽细节**：翘板凸棱 0.8 × 0.4、电源键凸点 Ø1.0 高 0.3、菜单键凹面 0.3，都是按 0.4 喷嘴放大过的（手板版是更细的原尺寸）。

## 结构

```
正面  ┌──────────── 亚克力 1.5（背印白框）────────────┐
      │  双面胶 0.15                                   │
      ├─┬──── 墨水屏 0.85 ────┬─────────────────────┬─┤ ← 中框前沿和屏幕正面同一平面
      │ │     泡棉 0.6        │  电池 4.5（缺角里）   │ │
      │ │     PCB 1.2         │                      │ │   中框：四周侧壁 2.0 + 4 个螺丝柱
      │ │     元件区 4.0      │                      │ │
      └─┴─────────────────────┴──────────────────────┴─┘
背面        后盖 1.6（4 颗沉头螺丝、2 根 PCB 压柱、传感器通风槽）
```

- **整机 118 × 67 × 9.48mm**（11-12 屏幕错开 3mm 加长，见下；11-13 亚克力 1.5 → 1.0，薄 0.5）。
- 11-06 时是 115 × 67 × 9.9mm（11-06 第一套 FDM 打印后觉得强度不够：侧壁 1.5 → 2.0，长边往外加所以外形高 66 → 67，短边往里加；后盖 1.2 → 1.6）。原设计 8.85：亚克力 1.5 比原来的 1.0 面框厚 0.5，再加面板和屏幕之间的 0.15 双面胶。
  11-13 改用 1.0mm 单面加硬亚克力（模型 `ACR = 1.0`）：面板四周粘在中框上、中间粘在屏幕玻璃上，有玻璃撑着，1.0 不会软；加硬面朝外，白色印刷和背胶在背面（未加硬面）。中框、后盖不受影响（中框前沿 = 屏幕正面）。
- **屏幕贴在亚克力背面**：双面胶只贴在白框区（屏幕玻璃非显示边）。亚克力再用同样的胶贴在中框前沿、4 个螺丝柱端面和左右两头的粘接台上。
  右头中段（y 14.8～42.2；11-08 按 GDEY0426T82 的 23.5 宽 FPC 改成 16.8～42.2，11-12 试装后往天线那边再开 2；最早是 18～44）不做粘接台，留给屏 FPC 绕过玻璃和 PCB 板边。屏厚同时由 0.85 改 0.926，当时整机厚约 9.98（亚克力 1.5）。
- **拆修**：只拧后盖 4 颗螺丝，面板和屏幕不用动（和原设计一样）。
- **屏幕错开 3mm（11-12）**：GDEY0426T82 的 FPC 比原来估的长，多出来的一截在排线头那点空当里折不下，屏幕往远离排线那头错开 3mm。
  模型里是 `SCR_DX = -3.0`（`eink-case.scad` 和 `gen_acrylic.py` 各一处，要改一起改）：屏幕玻璃、透光区、远端两颗螺丝柱和远端侧壁跟着挪；PCB、按键、Type-C、TF 卡、出声槽、通风槽的位置都不变。外形 115 → 118。
  排线那头的粘接台变成约 5.5 宽，中间 y 14.8～42.2 空出来给排线。远端那 3mm 屏背面下面没有 PCB，泡棉贴满屏背面即可。

| 项 | 方案 A（推荐） | 方案 B |
|---|---|---|
| 材料 | 透明 PMMA 1.5mm（想减反光可选 AG 防眩亚克力） | 白色不透明 PMMA 1.5mm（乳白 / 瓷白） |
| 加工 | 切外形；**背面**丝印白色，`PRINT_WINDOW` 框内不印 | 切外形和开窗 |
| 效果 | 屏幕被整块面板盖住保护，正面平整；侧面看是透明切割面，透出背面的白色 | 正面和侧面都是实心白色；屏幕玻璃露在开窗里 |
| 文件 | `acrylic-printed.dxf` | `acrylic-cutwindow.dxf` |

- 丝印在背面：DXF 是从正面看的图，下单时备注“背印，图纸为正视图”，让厂家自己镜像。
- **白墨要印 3 遍**（或白 2 遍再垫一遍浅灰）：白墨只印 1 遍是半透的，会透出后面屏幕的 FPC、胶带和中框的影子。下单时写明“白色不透光”。
- 方案 A 的侧面是透明的切割面，只是透出背面的白色，看上去偏玻璃感。想要侧面也是实心白，就选方案 B，或者让厂家把 A 的四周侧面喷白封边。
- 墨水屏不显示的边框本身是浅灰白色，透光区四周留的 0.5 和白色边框接得上，看不出一圈黑线。
- 两面保护膜到装配时再撕。外形公差 ±0.1。

**在嘉立创面板编辑器里下单**：导入 `acrylic-jlc.dxf`（单位 mm），按图层对应：

| DXF 图层 | 方案 A（透明 + 背印白） | 方案 B（白色亚克力开窗） |
|---|---|---|
| `OUTLINE` | 板框层 | 板框层 |
| `PRINT_FRAME` | 打印层：白框拆成左、右、上、下 4 块实心形状（编辑器不认洞，外形套窗口会整块填满）；导入后全选这 4 块，填充 #FFFFFF、去掉描边 | 不导入 |
| `WHITE_FRAME` | 同 PRINT_FRAME 的 4 块；编辑器导入选项里有白色遮盖层时用，没有就不导入 | 不导入 |
| `WINDOW` | 透明控制层；下拉框里没有这层就不导入 | 挖孔层 |
| `TAPE_CUTOUT` | 背胶挖空层 | 背胶挖空层 |

11-13 第一次导入时只有板框和背胶，整块是透明的、没有白框（编辑器没把 WINDOW 当成"其余印白"），所以加了 `WHITE_FRAME` 层直接给出白框形状。

导入后看预览：从正面看 Type-C 那头在左时，透光区离左边 17.13、离右边 7.07。反了就是被当成背面视图了，要镜像。
编辑器里的背胶默认铺满整块面板，`TAPE_CUTOUT` 挖掉显示区和排线那头；外圈比外形小 0.3 那一圈在编辑器里画不出来，可以不管，或下单备注“背胶外边内缩 0.3”。

**背胶（让亚克力厂家一起做）**：DXF 的 `TAPE` 层是胶的形状，示意图见 `acrylic-tape.svg`。下单备注：

> 背面（丝印面）贴双面胶：0.15～0.17mm 薄型双面胶（3M 9495LE 或同类，透明或白色），按 TAPE 层模切，贴在印刷完成后的背面，背面离型纸保留不撕。图纸是正视图，胶在背面，请镜像。

- 胶是一整片"回"字形，一次同时粘住中框前沿、4 个螺丝柱、两头粘接台和屏幕玻璃的边框（它们在同一个平面）。
- 内边离屏幕显示区 0.8（印刷透光区是 0.5），胶边藏在白墨后面，正面看不见；外边比面板外形小 0.3，透明侧边看不到胶边。
- 屏排线那头只在玻璃上贴 1.7mm 一条（离显示区 0.8～2.5）。再往外是驱动芯片和排线压接的台阶，以及排线绕过玻璃和 PCB 板边弯折的空当，都不贴胶。
  **下单前用卡尺量一下实物**：排线那头，从显示区边缘往外，平整的屏幕表面有多宽。少于 2.5mm 的话，改 `gen_acrylic.py` 的 `FPC_STRIP` 重跑。
- 那一条中间断开 2mm 当通气口：亚克力和屏幕之间是一层 0.15mm 的空气，完全封死的话热胀冷缩、气压变化会让它鼓起来或吸进潮气。
- 用力按面板中间偶尔会看到彩色波纹（牛顿环，亚克力被按弯碰到了屏），松手就没了。经常出现的话，胶换 0.2～0.25mm，或面板换 AG 防眩亚克力。

## 装配

1. 键帽从壳内装进底边三个孔（菜单圆键、翻页翘板、电源圆键），上沿法兰片贴住侧壁内表面。
2. 撕掉亚克力背胶的离型纸（厂家已贴好胶），和中框外形对齐贴到中框前沿。
   **先清洁**：在水汽重的地方（刚放过热水的浴室）做，灰尘最少。亚克力不要用酒精擦（激光切边有应力，会出细裂纹），用清水加一点洗洁精、超细纤维布擦干。
   屏幕正面先揭掉出厂保护膜（一般有个小拉手），再用干的超细纤维布和除尘贴清干净。
3. 中框正面朝下放平，屏幕正面朝下从背面放进中框：侧壁给玻璃定位（长边每边只有 0.3 间隙），压实贴在亚克力上，透光区就自动对准显示区。只按屏幕边框，不要按显示区。
4. 屏背面贴泡棉、电池支撑片和电池；屏 FPC 绕过去插 FPC1；PCB 放在泡棉上，电池线插 U3。
5. 盖后盖：两根压柱插进 MH1、MH2，把 PCB 压在泡棉上；拧 4 颗螺丝。

## 和原设计（eink-docs v4.43 以前）不一样的地方

下面几条 eink-docs v4.44 已经同步。

1. **整机厚度 8.85 → 9.5 → 9.9（11-13 亚克力改 1.0 后 9.48）**，原因见上。按键、TF 卡、Type-C 的开孔高度都是从 PCB 底面算的，不受影响。
2. **喇叭出声槽从 Type-C 那头挪到底边**（中心 x 96.9 对准喇叭，3 条 0.9 × 2.7，间距 1.8；11-06 用户定由 7 条减到 3 条）。原来 5 条槽在右侧短边 y 53.9～61.1，后 3 条和右下角螺丝柱（107.7, 60）重叠，开不出来。底边正对喇叭 LS1 的长边，声音路径更短。
3. **翻页翘板去掉中间的支点筋**。键帽上沿有法兰片卡住侧壁时，支点筋和法兰会互相顶死（压一头时另一头要往外走，被法兰挡住）。现在翘板以另一端的法兰为支点转：压上半只触发 SW1，压下半只触发 SW2；正中按下去两个都会触发，固件里两键同时按下时忽略即可。
4. **键帽法兰片只做在开关本体上方**（离 PCB 底面 ≥3.0），按下 0.4 也碰不到 EVQPUC02K 本体；法兰下面和两端都是 45° 斜面（FDM 侧躺打印不用支撑），比开孔每边宽 0.8，卡在侧壁内表面上方。键帽内表面离推杆顶端 0.1（推杆顶端在板边外 0.6），所以不用再加凸点。
5. **传感器侧面通风**：底边对着 U7/U11 加了 3 条 0.8 × 2.4 的槽（文档里是“打样后再定”）。不想要就删掉 `eink-case.scad` 里 `SENS_X` 那一行。
6. 后盖加了 **Type-C 顶面压块**（离接口外壳 0.1），拔插时接口不会被撬起；原文档的“背后加筋”没做，因为接口后面紧挨着 D1、R1、R2。
   **Type-C 开孔分两半**（11-06）：开孔 9.7 × 3.9 顶上离后盖只剩 0.4，FDM 是悬空的薄条、容易下垂和断，PU 复模也容易撕。现在中框在开孔上方开 11.7 宽的 U 形口直通后盖，后盖伸下一块舌头（11.7 × 1.5，伸到开孔中心高度）补上开孔上半圈，间隙 FDM 0.15 / 手板 0.1。外面看开孔两边各多一道 2.3mm 的短竖缝。
7. **充电灯窗口不正对 LED，往远离 Type-C 的方向挪了 2.3**（圆孔 Ø1.5，中心 y 54.0、离 PCB 底面 1.7；LED1 在 y 51.69）。LED1 离 Type-C 中心只有 6.35，USB-C 插头胶壳最宽 12.35（规范推荐上限），会盖到 y 51.5，正对 LED 开窗的话插着线充电时灯被挡住。挪开后离最大胶壳还有 1.7；LED1 是侧发光，离侧壁约 5.5，光在空腔里散开，偏 23° 亮度还有八成多。**下一版 PCB**：把 LED1 挪到离 Type-C 中心 ≥9mm（y ≥ 54.5），窗口就能再正对 LED。

## 打样后要量的

- Type-C 前端离壳外表面约 2mm：有些线的插头塑料头短，可能插不到底。插不到底就把开孔外侧做一个 12.4 × 6.4、深 1.0 的沉台。
- 键帽手感和间隙（`CLR`）、翘板两头会不会一起触发。
- 屏幕贴到亚克力后，透光区和显示区四边是否都留出约 0.5 白边；白框有没有透出后面的影子。
