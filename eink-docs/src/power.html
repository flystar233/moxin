供电与充电

从 Type-C 进来的 5V 先经过静电和浪涌保护，再分成两路：一路给电池充电，一路经负载共享电路直接给系统供电；系统电压 VSYS 再经 LDO 变成 3.3V。这一页每个关键取值都配了计算器，可以拖动看边界。

Type-C 输入与保护

烧录直接用 ESP32-S3 原生 USB（GPIO19/20），不需要 USB 转串口芯片。

  • CC 下拉：CC1、CC2 各接一颗 5.1k（R2、R1）到 GND，C-to-C 充电器看到下拉才会输出 5V。两个 CC 必须各用一颗电阻：共用一颗时，带 e-marker 芯片的 C-to-C 线会把设备误判为音频附件而不供电，树莓派 4 早期版本就出过这个问题。
  • VBUS 电容与振铃阻尼：插带电的 USB 电源（USB-A 充电头、电脑口、充电宝）时，线缆约 0.5～1µH 的电感和几乎没有内阻的陶瓷电容组成 LC 回路，峰值可到 7～8V。D3 钳位约 9V，压不住这一段；开机时振铃还会经 D2 到 VSYS，打到 U4、U9 的电源脚。v3.4 按 silkscreen-pcb Rev 1.01 的做法改为两颗电容：C34 1µF 直接接 VBUS、紧挨 USB0，负责高频去耦和 ESD 回路；C35 10µF 的地端经 R25 1Ω 接地，电阻把振荡能量消耗掉，峰值约 5.6V。稳态时电容不充放电，R25 上没有电流，VBUS 不掉压。阻值在 0.5～1Ω 之间都有效。USB-C 对 C 的充电器插上后才升压，本来就不振 待实测。

USB 静电保护 D1 USBLC6-2SC6

防插拔和触摸时的静电打坏 ESP32 的 USB 引脚。它对 VBUS 上的大能量浪涌作用有限，VBUS 过压由 D3 负责。

  • 引脚：1、6 为一组 I/O（接 D+），3、4 为另一组（接 D−），5 接 VBUS，2 接 GND（已对照 ST 规格书）。
  • 直通式走线：D+/D− 从 Type-C 进入 1、3 脚焊盘，再从 6、4 脚出来连到 ESP32，信号线直接穿过器件焊盘，不要从主线上引分支去接。
  • 紧贴 Type-C 放置，在接口和 ESP32 之间；GND 脚就近打 2 个以上过孔。

VBUS 浪涌保护 D3 SMF5.0A

  • 阴极（色带一端）接 VBUS，阳极接 GND，反接会直接把 VBUS 短到地。
  • 放在 Type-C 的 VBUS 引脚旁边，在 D1 和 U1 之前；GND 端就近打过孔。
  • 工作电压 5.0V，击穿电压最小约 6.4V。部分充电器输出 5.2V 左右，只会让漏电流略增。
为什么不用更高电压的 TVS

silkscreen 的 VBUS 用 SMF6.5CA，漏电更小。但钳位电压随型号升高：SMF5.0A 在额定浪涌电流下约 9.2V，SMF6.5A 约 11.2V，而 TP4056 系列输入的绝对最大值是 8V。本设计没有 silkscreen 那样的 PPTC 保险丝和电源选择芯片挡在前面，选钳位更低的 5.0V 型号更合适。

注意

本方案只用 CC 下拉电阻请求 5V。以后若改成 PD 诱骗 9V 或更高，D3 会被击穿烧毁，U1 也会超压，必须同时改电路。

TP4056X 是 TP4056 的改进型号，引脚兼容。TP4056X 规格书同样按 I = 1200 / R 设定充电电流，R20 2k 约 600mA（已核对）。TEMP 引脚在电池不带 NTC 时接 GND；CE 接 VIN；BAT 端放 C7 10µF。

负载共享

TP4056 系列没有电源路径管理。系统直接并在电池上时，充电芯片会把系统电流也当成充电电流，电流降不到终止阈值，永远判断不了充满。所以加一组负载共享电路：插 USB 时系统走 D2，电池只充电；拔掉后 Q1 导通，电池接管。

为什么栅极直接接 VBUS

插 USB 时栅极就是 VBUS，源极是 VBUS 减去 D2 的压降，栅源电压约 +0.35V，Q1 可靠关断，电池不会偷偷供电。不要在栅极和 VBUS 之间串 10k 这类电阻：它和 R21 10k 分压后栅极只剩 VBUS 的一半（约 2.5V），栅源电压约 −2.1V，Q1 直接导通，插着 USB 时电池也在放电、充电永远充不满。插 USB 的振铃经 R25 阻尼后约 5.6V，即使 D3 钳到约 9V，栅源电压也远小于 AO3401 的 ±12V。

D2 和 Q1 汇合的节点叫 VSYS_IN，经 U14 才到 VSYS，U14 由电源键 SW3 和 ESP32 控制（见下一节）。VSYS 上有 C9 10µF 和功放旁的 C36、C37（2 × 22µF 陶瓷），拔 USB 的瞬间先由 Q1 的体二极管供电，VSYS 比电池低约 0.7V，直到 VBUS 上约 20µF 的电容经 R21 放电、Q1 的栅极降下去为止。R21 原来是 100k，这段约 0.5～1 秒，电池电压低（约 3.6V 以下）时 3V3 会掉到约 2.9V，正好碰上刷屏或 Wi-Fi 发射就可能欠压复位；在长按开关机方案里复位就等于断电，而且来不及刷关机画面。v4.34 定为 10k（PCB 不用动），这段缩短到约 0.1～0.2 秒，代价只是插着 USB 时多耗约 0.5mA，用的是 USB 的电。拔掉 USB 后 D2 的反向漏电流过 R21（与 R28、R29 并联），在栅极上抬起的电压只有 100k 时的约 1/7，壳内发热、肖特基漏电变大时 Q1 也能充分导通。10k 和板上其他十几颗 10k 同料号，不增加新料。

电源键与电源开关 SW3

v4.26 起取消拨动开关，改成长按电源键 3 秒开关机。D2 和 Q1 汇合成 VSYS_IN，经负载开关 U14（TI TPS22917）到 VSYS；U14 的 ON 脚由电源键 SW3 和 ESP32 一起控制。这样关机前固件能先在墨水屏上刷一张关机画面，断电后屏幕一直显示它，一眼看得出是关机还是在睡眠；低电量时也能自己关机。

  • 开机：SW3（EVQPUC02K，和侧键同型号）的 1、3 脚内部相连接 PWR_KEY，2、4 脚内部相连接 VSYS_IN，四个脚都不接地（v4.33 核对 EDA 时发现 2、4 脚接了地、1 脚接 VSYS_IN，平时 PWR_KEY 常接 VSYS_IN 关不了机，按下还会把 VSYS_IN 短到地，已改正）。按下时 PWR_KEY 变成 VSYS_IN 的电压（用电池时是电池电压，插着 USB 时约 4.6V），经 D7（BAV70，安世 BAV70,215，SOT-23）把 ON 拉高，U14 打开，VSYS 和 3V3 上电。ESP32 启动后第一件事把 GPIO4（PWR_HOLD）拉高，经 D7 的另一个阳极锁住 ON，并用 gpio_hold_en 保持，深睡也保持（GPIO4 是 RTC GPIO）。固件数满 3 秒才算开机，提前松手就先 gpio_hold_dis、再拉低 PWR_HOLD，直接断电（v4.31 补充：hold 开着时 gpio_set_level 不生效，只拉低会关不掉）。从上电到固件拉高 GPIO4 约 0.3～0.5 秒（S3 带 Octal PSRAM），这段靠按键撑着；点一下就松手的误触，固件起来发现键已经松开，就直接断电。
  • 关机：开机状态下长按 SW3 3 秒，固件先全刷一张关机画面（约 2～3 秒），等 EPD_BUSY 变低（刷新完成）后给 SSD1677 发深度睡眠命令（0x10），再把电量计 U10 的 MODE 写成 0xC0 让它睡眠（v4.43），等松手后 gpio_hold_dis 并把 PWR_HOLD 拉低（v4.31：刷新没完成就断电，画面可能残缺或留残影），R30 1M 把 ON 拉到地，U14 关断（v4.27 由 100k 改 1M：开机期间 PWR_HOLD 经 D7 一直有电流流过 R30，100k 时约 27µA，1M 时约 2.7µA）；QOD 接 VOUT，VSYS 上的电容经内部约 150Ω 在几十毫秒内放掉。必须等松手：按着键时 ON 还被按键拉着。低电量时固件可以先刷"请充电"再自己关机。
  • 读按键：PWR_KEY 是电池电压，不能直接进 GPIO，经 U15（2N7002）反相成 PWR_KEY_N 接 GPIO1，R32 10k 上拉到 3V3，按下为低；和 KEY1～KEY3 一样可作 ext1 深睡唤醒源，短按可以留给别的功能。按键卡住（比如在包里被一直压着）时 ON 一直被按键拉着，关不了机，按住期间 R32、R31 上约 0.37mA；固件只能把 GPIO1 从唤醒源里去掉，免得反复唤醒（F6）。R31 100k 是 PWR_KEY 的下拉，松手时 U15 和 D7 的按键这一路都关掉。关机时 3V3 没电，PWR_KEY_N 只接在 U15 漏极和 R32 上，不会倒灌。
  • D7 为什么用硅管：TPS22917 的 ON 高于 1V 算开，低于 0.35V 才保证关。肖特基二极管的反向漏电随温度涨得快，零点几微安流过 1M 的 R30 就会把 ON 抬到中间的不确定区；BAV70 是硅管，漏电只有 nA 级。硅管压降约 0.7V，GPIO 的 3.3V 过去还有约 2.6V，按键这一路是电池电压减 0.7V，都远高于 1V。
  • 负载开关 U14：TPS22917DBVR，SOT-23-6，1 VIN、2 GND、3 ON、4 CT、5 QOD、6 VOUT；ON 高有效（带 L 的是低有效版，不要买错）。导通电阻 90mΩ（3.6V，典型），1A 峰值时压降约 90mV；开启时静态电流 0.5µA、关断 10nA，深睡电流几乎不受影响（SY6280 这类限流开关开启时要 38µA）。CT 经 C38 2.2nF 接到 VIN（v4.27 文档定的是 10nF，EDA 实际用 2.2nF，v4.33 按 EDA 更正），开启时间按手册 CT = 1000pF 的数据等比放大，约 5～9ms，VSYS 上 C9、C28、C36、C37 等约 60µF 的电容（陶瓷电容加偏压后实际约 40µF）充电电流约 30mA，电池保护板不会误判；3V3 比 EN 的 RC 延时（R27、C32 约 10ms）先到位，ESP32 正常启动，样板上连续开关机 20 次确认；C39 10µF 是输入电容。没有限流：VSYS 对地短路时靠电池保护板断电，插着 USB 时靠 USB 口自身的限流。常开反向电流阻断，拔 USB、VSYS_IN 短暂下跌时也不会从 VSYS 倒流。
  • 关机时仍能充电：U1 接在 VBUS 和电池上，在 U14 前面，不受开关影响。
  • 关机时插 USB 只充电，不开机：USB 经 D2 只能到 VSYS_IN，ON 没人拉高，U14 不开，系统不上电。想做成插 USB 就开机显示充电画面，可以在 VBUS 和 ON 之间再加一个二极管，但那样插着 USB 就关不了机，这一版不做。
  • 关机电流：电池保护板约 3～6µA、U1 的 BAT 端反向电流约 1～3µA、D2 反向漏电约 1～5µA（关机时 Q1 仍导通，VSYS_IN 等于电池电压）、U14 关断 10nA，加上直接接电池的电量计 U10 睡眠约 0.5µA（v4.43 起关机前由固件让它进睡眠，原来一直工作约 15µA）和时钟 U6 约 0.3µA（v4.27 起接电池，关机也走时），合计约 6～15µA，每月约 4～11mAh，放半年约用掉 2%～4% 电量（1500mAh）。RESET 硬关机、欠压掉电这类固件来不及处理的关机，U10 仍在工作，这一次关机期间按原来的约 20～35µA 算。松手时按键、R30、R31 都没有电流。
  • 烧录、复位和下载模式：U14 只认 ON，USB 也只送到 VSYS_IN，所以没人拉高 ON 时板子就没电，插着 USB 也一样。分几种情况：
    • 平时烧录：固件跑着、插着电脑时不深睡（见固件页），电脑上一直有原生 USB 串口，esptool 通过 USB 让芯片自己复位进下载模式，不拉 EN。GPIO4 是 RTC GPIO，gpio_hold_en 大概率能撑过这种复位，这样不用按任何键；要在样板上实测。
    • 软件重启、看门狗复位、OTA 后重启：同样靠 gpio_hold_en 撑住（GPIO4 复位时没有内部上下拉，hold 一丢 R30 就把 ON 拉低）。撑不过就在 ON 对地补一颗 1µF（建议在 R30 旁预留一个不贴的 0603 位，EDA 待加）：和 R30 组成约 1 秒的保持，固件约 0.3 秒就会重新拉高 GPIO4；代价是关机时 ON 要多等 1～2 秒才降到关断电平。
    • 新板第一次烧录、固件坏了要手动 BOOT + RESET：芯片里没有程序去拉高 GPIO4；按 RESET 会拉低 EN、清掉 hold，板子当场断电。这两种情况要一直按着 SW3 直到烧完，或者用下面的开发用短接。
    • 开发期免按键（v4.35 定）：ON 和 VSYS_IN 之间预留一个 0603 0Ω 焊盘 R33，默认不贴，EDA 里放在 U14 正下方约 4mm（U14 和 TF 卡座之间，v4.41），ON 和 VSYS_IN 各走几毫米过去，不贴时这两根线是悬空的短截线，没有影响。调试期贴 0Ω 或点锡短上，等于一直按着电源键，第一次烧录、救砖、手动 BOOT + RESET 都不用按 SW3；ON 最高约 5.2V，低于 6V 上限，D7 两路都反偏，只多 R30 上约 4～5µA。贴上后长按关机和 RESET 硬关机都失效，带着电池放在桌上也不会断电；量产不贴，不改产品行为。必须接 VSYS_IN，不能接 VSYS：VSYS 在 U14 后面，接上后一按开机就自己锁住 ON，再也关不掉。原来的方案 B（+5V 经 1M 接 ON）不采用。
    • RESET 等于强制断电：反过来也有用，死机时电源键关不掉（固件不响应），按 RESET 可以硬关机。RESET、BOOT 装壳后平时按不到。

稳压 U4 RT9080-33GJ5

v4.32 由赫尔 HE9073A33M5R 换成立锜（Richtek）RT9080-33GJ5：3.3V、600mA，TSOT-23-5，引脚是 1 VIN、2 GND、3 EN、4 NC、5 VOUT，和 HE9073A33M5R 完全相同，PCB 不用改（规格书 DS9080-09 已核对）。EN 是 CMOS 输入，规格书写明不能悬空、可以直接接 VIN，这里接 VSYS 让它常开；EN 高于 0.9V 开启、低于 0.4V 关断，VSYS 最低 3.0V，余量充足。4 脚 NC 悬空或接地都行。静态电流典型 2µA、最大 4µA，比 HE9073 的约 0.3µA 多约 2µA，深睡底电流基本不受影响。输入 C9、输出 C10 各 10µF 紧靠芯片（规格书要求输出电容 ≥1µF）；模组 3.3V 引脚附近另有 C5 22µF 吸收 Wi-Fi 瞬态电流。EN 常开，U4 跟着 VSYS 走：平时的"待机"是深睡，长期不用时长按 SW3 3 秒关机，U14 断开 VSYS，U4 一起断电。

换它的原因是压差。规格书给的是 600mA 时典型 0.31V、最大 0.53V（输出 ≥3V），约 0.52Ω（最大约 0.88Ω）；HE9073 约 1Ω。Wi-Fi 发射 0.36A 时，LDO 上少掉约 0.17V，低电量时 3V3 的余量明显变大（F7，见下面的计算器）。电流上限也从 500mA 提到 600mA，ESP32-S3 Wi-Fi 发射峰值约 0.36A，叠加 TF 卡写入和屏刷新也还有余量。静态电流低的 LDO 负载突变时响应通常偏慢，样板上仍要看 Wi-Fi 发射瞬间 3V3 的跌落。注意认准立锜原厂料，立创上有其他品牌标"RT9080"的兼容料，参数不一定相同。

线性稳压的损耗等于压差乘以电流，最坏情况是插 USB 时（VSYS 最高）。规格书建议结温不超过 125°C。

TJ = TA + (VIN − 3.3) × I × θJA。RT9080 规格书给的 TSOT-23-5 θJA 是 189.4°C/W（JEDEC 标准板），4 层评估板上是 100.7°C/W；实际铺铜后介于两者之间。

本设计 3V3 的持续电流：深睡是微安级，常连 Wi-Fi 开自动浅睡时平均约 3～10mA，下载和拉取时 100mA 上下且只持续几秒。只有插着 USB 长时间大流量联网时才会接近 250mA。充电时 U1 就在旁边发热，所以打样验收第 11 步仍要实测。

电池与保护

注意

TP4056 不提供过放保护，本方案依靠电池自带的保护板。购买时确认保护板有过充、过放、过流和短路保护，否则 ESP32 欠压关机后，睡眠电流仍会把电池放到过低而损坏。电池经 MX1.25 2P 插头接到 U3。这种插头的线序没有统一标准，买来的电池第一次插之前一定用万用表确认红线对 1 脚 BAT+，插反会直接烧掉充电芯片。

电压与电量检测：都由下一节的电量计 U10 给出。v1.3 去掉了原来接 GPIO1 的 1M + 1M 电阻分压：U10 的 14 位 ADC 比 ESP32 未校准的 ADC 准，分压电路重复，去掉后深睡少约 2µA。GPIO1 现为空闲脚（见引脚页）。样板上需要对照时，用万用表测 C2 两端（VBAT）。

电量计 U10 CW2015

只看电压估电量很难准：锂电池在 3.7～3.9V 这段曲线很平，几十 mV 的误差就差出 10% 以上的电量，负载一变读数还会跳。v1.1 加一颗赛微 U10 CW2015CHBD：内部 14 位 ADC 测电池电压，再按电池模型和内阻补偿算出剩余电量（SOC），直接从 I2C 读百分比。

它不测电流

CW2015 不用采样电阻，规格书写明是 sensing resistor free。它给出的剩余时间（RRT）也是从电压变化推算放电电流得到的，没有电流读数。需要真实电流（库仑计），要换同厂带采样电阻的 CW2017/CW2217，或 INA219 一类电流监测芯片。

  • R18、R17 的取值按规格书 Fig10 的系统侧接法取 100Ω 和 470Ω，配两颗 1µF。已对照原图：R18 100Ω 接 VDD，R17 470Ω 接 CELL。CELL 输入阻抗约 10MΩ，470Ω 带来的误差可以忽略。

  • 功耗：工作电流 15µA（最大 20µA），睡眠 0.5µA。关机时睡眠（v4.43），开机和深睡期间工作：深睡时要靠它的 ALRT 在低电量时唤醒，深睡底电流因此增加约 15µA（中值从约 35µA 到约 50µA，明细见功耗页）。桌面拉取模式平均约 2.5mA，这点增量不到 1%；纯待机从约 4 年降到约 3 年，实际仍受电池自放电限制。

固件要做的事 待核实

  1. 上电先唤醒：MODE（0x0A）的 Sleep 位默认是 11，芯片上电后处于睡眠，要写 0x00 才开始测量。
  2. 检查电池模型：读 CONFIG（0x08）的 UFG 位，确认电池模型已生效；要换成按 454261 定制的模型时，在这里写入（F17）。
  3. 读电量：SOC（0x04）高字节就是整数百分比，低字节是 1/256%；VCELL（0x02～0x03）是 14 位，每 LSB 305µV。
  4. 设报警门限：CONFIG 高 5 位 ATHD 设为 5%（默认 3%），电量降到门限时 ALRT 拉低，GPIO16 把设备从深睡唤醒，屏幕刷成"请充电"。
  5. 睡前清 ALRT：RRT_ALRT（0x06）最高位是 ALRT 标志，写 0 清除。不清的话 GPIO16 一直为低，造成唤醒循环（F6）。规格书说明清除后 SOC 一直低于门限也不会再报警。
  6. 关机前让它睡、开机后重估（v4.43）：每条主动关机的路径（长按关机、低电量关机、开机 3 秒内提前松手）在拉低 PWR_HOLD 之前写 MODE = 0xC0，U10 进睡眠，关机期间约 0.5µA。开机第 1 步照常写 0x00 唤醒。睡眠期间它不测量，SOC 停在关机时的值：放了很久会偏高，关机充过电会偏低。所以唤醒后如果没插 USB（GPIO9 为低），在开 Wi-Fi 之前写 MODE = 0x30（QSTRT = 11）让它按当前电压快速重估，再写回 0x00；电池放了一段时间，电压已经稳定，按电压估得比较准。插着 USB 时充电电流会把电压抬高，不做快速重估，等它自己收敛，拔掉 USB 后的第一次开机再做。样板上实测：关机充 1 小时后开机，看 SOC 和 VCELL 对不对得上。

有了 U10，充电时也能显示电量百分比，不必再只显示"充电中"。低电量门限仍按电压判断，因为门限保护的是 3V3 的余量（F7）。电压改读 U10 的 VCELL，在开 Wi-Fi 之前、静置时读。

低电量时的电压余量

电池快没电时，Wi-Fi 发射峰值和大音量朗读叠在一起，电流在电池内阻、Q1、U14 和 U4 上层层压降，3V3 可能掉到 ESP32-S3 的 3.0V 下限附近（F7）。

结论：v4.32 换成 RT9080 后，只开 Wi-Fi 发射时 LDO 压差仍是最大的一项，但比 HE9073 小了约一半。电池 3.5V 时只开 Wi-Fi 发射，3V3 约 3.18V（按最大压差约 3.05V）；3.7V 时满幅朗读加发射约 3.18V（最大压差约 3.05V）。HE9073 时这两种情况都只有约 3.0V。v0.9 定的低电量策略（3.7V 以下限制音量、3.6V 停止朗读、3.5V 停止联网，见固件页）先不改，留出余量；样板上用示波器看到 3V3 最低点确实有富余，再考虑把门限各下调约 0.1V，多用一点电池容量。454261 内阻约 0.2Ω，计算器默认值已按 0.22Ω 设。
