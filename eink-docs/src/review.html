看起来像错误但不是

审图或板厂 DFM 检查时，下面这些容易被当成错误，其实是有意为之。

  • Q1 像是接反了D 极接电池、S 极接 VSYS_IN。这样体二极管从电池指向 VSYS_IN，拔掉 USB 的瞬间先由体二极管供电，系统不掉电。
  • Q1 栅极直接接 VBUS，没有串联电阻插 USB 时栅源电压等于 D2 的压降，约 +0.35V，Q1 可靠关断。串 10k 这类电阻会和 R21（10k）分压，栅极只剩 VBUS 的一半，Q1 直接导通，插着 USB 时电池也在放电。
  • FPC 13、14 脚叫 SCL、SDA 却接 SPI这是屏厂的命名，实际是 SPI 时钟和数据。
  • U9 接 VSYS 不接 3.3V为了更大的输出功率，同时让音频峰值电流不经过 LDO。
  • 喇叭两根线都不接地NS4168 是桥式输出，任何一端接地都会烧功放。
  • GPIO16 上接了两个芯片的中断U6 的 INT 和 U10 的 ALRT 都是开漏输出，线与后共用 R3 上拉；醒来后两个芯片的标志都读一遍，就知道是谁触发的。
  • U6 没有纽扣电池掉电后靠电脑端下发的时间恢复，开机检查 VL 位就知道时间是否可信。
  • U8 的 INT1 没有上拉它是推挽输出，不需要。
  • 没有 USB 转串口芯片S3 原生 USB 负责烧录和串口，H3 是备用。
  • GPIO39～42 是 JTAG 脚却接了屏的 SPI调试走内置 USB-JTAG，这四个脚当普通 GPIO 用。它们在模组下边一排、正对 FPC1，屏的线最顺；GPIO39 复位期间的弱上拉只是让 SCK 停在高电平，没有时钟沿，屏不会收到数据。
  • PCB 朝屏一面没有元件屏幕玻璃只有 0.85mm，需要整面平整支撑。
  • CO2、温湿度传感器周围有一条 L 形槽隔热用。槽不切到板边，不改变板子外形。
  • PCB 是 L 形，缺了一个角左上角 63×43mm（v4.6 起，原在左下）留给 4.5mm 厚的电池。电池直接贴在屏背面，整机约 8.8mm；缺角处的屏幕由贴在背面的支撑片承托。
  • 电池座用 MX1.25 而不是常见的 PH2.0PH2.0 座高 4.6mm，比这块电池还高，会把整机撑厚；U3 用 MX1.25 卧贴座，高 3.6mm，在限高内。注意插头线序没有统一标准，插之前先量。
  • 关机后插 USB 只充电，不开机负载开关 U14 在负载共享之后，USB 和电池都要经过 U14 才能到 VSYS；充电芯片 U1 接在 U14 前面，所以关机也能充电。v4.26 起 U14 的 ON 由电源键 SW3 和 ESP32 控制，关机时没人拉高，插 USB 不会开机。
