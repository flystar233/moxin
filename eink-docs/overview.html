2.3整体架构

电脑端的 Python 常驻程序采集 CPU、GPU 和 AI 数据，同时兼任书库和朗读服务：把书排版成页面图片，把章节合成为语音。ESP32-S3 驱动墨水屏和 I2S 功放，时间由电脑端在通信时一并下发。U6 在断网或深睡时保持走时；U8 判断摆放方向，转动设备时也能唤醒 ESP32。

2.4设计原则

  • 待机电流就是续航。墨水屏保持画面不耗电，所以功放关断下拉、方向变化中断、去掉电池分压、静态 IP 快速重连，都是在省深睡和醒来的那点电。
  • 重活放服务端。排版、字库、语音合成、用量统计都在电脑上做，设备只显示图片、播放 MP3，改排版不用重新烧录。
  • 一个方向传感器换两种产品。同一套硬件靠摆放方向切换监控器和阅读器，按键跟着方向重新映射。
  • 大电流不过 LDO。功放直接吃 VSYS，LDO 只管数字部分，低电量时 3.3V 不会被音频拖垮。
  • 让屏自己驱动升压。板上只放功率器件，开关时序由屏内控制器决定，所以器件值要贴着参考设计取。
  • 先保证能调试。UART 焊盘、电源和 I2C 测试点、BOOT/RST 按键、插 USB 不睡，都是为了样板出问题时能看到发生了什么。
